# Tally Counter Flutter App

A clean, responsive, and modern Material 3 Tally Counter application built with Flutter.

## Features
- **Increment & Decrement**: Quick taps with fluid animations.
- **Reset with Confirmation**: Avoid accidental resets.
- **Custom Step Size**: Adjust counter step (+1, +5, +10).
- **Vibration/Haptic Feedback**: Standard Flutter haptic feedback on tap.
- **Clean Material 3 UI**: Light/Dark theme support.

## Getting Started
1. Ensure you have Flutter installed (`flutter --version`).
2. Run `flutter pub get` in the root project directory.
3. Launch the app using `flutter run`.
